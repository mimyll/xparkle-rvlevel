# 0.4.0

First public preview with standard Home Assistant card examples by default and an optional theme-aware caravan visualization. The earlier green appearance is available explicitly as `appearance: mint`. The optional card now has a stable no-store asset URL; reload browsers after updating. Replace old versioned resource URLs once when upgrading from 0.3.

Native entry/options/entities/cache are unchanged. Before updating, stop measurements, confirm cleanup and successful native unload, retain old component source, update through Marketplace and restart while disabled. Enable the same entry afterward. This release is deliberately restricted to the README's exact runtime matrix. Physical accuracy, output signs, internal sensor cadence and battery life remain unverified. Calibration remains disabled. Repository availability does not mean inclusion in the default catalog.
